Every .md and .markdown file in the folder is imported, subfolders included, and the relative path becomes the document name. The folder is the source of truth: changes are pulled in, and a file deleted from it is removed from the Knowledge Base. Nothing is ever written back to your disk.

Split a document

The model is given the folders that already exist in your linked folder and is asked to place each file in one of them. Figures that do not appear in your source are rejected rather than written. Nothing is written until you choose to.

About

What this extension does, and where your data goes.

YouTube Auto Reply watches your open video page for comments that match your triggers, asks the local model you configured for a reply, and drafts that reply into the comment box for you to send.

Version 1.1.0. Generation runs entirely on your own machine through LM Studio, so comment text is never sent anywhere else.

Help

The short path from a fresh install to a working reply.

  1. Start LM Studio and load a model on its local server.
  2. Set the Base URL and pick the Model, then save.
  3. Run Test LM Studio Connection, then Test Chat Completion.
  4. Add trigger phrases, then turn the extension on from the popup.

Tips

  • Use a local model like LM Studio for privacy and faster replies.
  • Add common phrases your audience uses in the Triggers section.
  • Include product name, link, or other fixed info in Static context.
  • Test the connection and chat completion to make sure everything works.
